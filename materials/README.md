## 已发现的原题问题

1. 第2章作业及 Quiz 01 的字符串加整数单选题：弯引号原样是语法错误；换成普通引号后是运行时 TypeError，选项不严谨，解析已区分。
2. 第3章作业变位词题样例 3：`Wellcom` 与 `mocllew` 忽略大小写后互为变位词，但原输出为 `no`，与题意和样例 1 冲突。保留原样例，参考解答按题意输出 `yes`。
3. 第2章作业的近似和题，“小于序列和的最大整数”与提示 `floor` 在整数边界存在差异，参考解答按题目提示的 floor 实现，解析说明。
4. 十六进制过滤题未规定无合法字符情形，参考解答约定输出空行和 0，解析说明。
5. 第2章作业 Unicode 码题未约定数值形式，同时给出十进制和 U+ 码点。
6. 部分原代码具有整体前导缩进或弯引号，题干仍保留，解析按课程意图说明相应问题。

新增 41 道编程解答核对 59 组原样例：58 组一致，1 组为上述变位词题已记录的源资料冲突。未在 PTA 平台提交验证。

## 整理脚本

`extract-materials.py` 需要 beautifulsoup4、markdownify、python-pptx，读取原始材料并生成提取稿。`prepare-solutions.py` 与 `programming-solutions.py` 保存人工核对的答案和解析；`publish-materials.py` 生成网页 Markdown。人工修订网页后不要直接重新导入，以免覆盖。正常内容维护直接编辑 `docs/` 内的 Markdown 即可。

## 详细解析维护

所有 240 道题已补充关联知识讲解，编程题另有针对当前代码的步骤与边界说明。题干、参考答案和原解析保留。

- `materials/explanation-guides.md`：按知识点组织的补充讲解，可直接修改文字与例子。
- `scripts/enrich-explanations.py`：题目与讲解的对应关系，以及逐道编程题的步骤说明。
- 修改后运行 `python3 scripts/enrich-explanations.py` 更新网页；重复运行不会重复插入。
- 重新运行发布或 Quiz 02 导入脚本后，也应运行一次上述命令恢复补充讲解。
- 直接修改题目特有的原解析时，可编辑 `docs/` Markdown；自动补充区域由 `teaching-notes` 注释标记，修改该区域应同步回上述来源，避免下次生成覆盖。
