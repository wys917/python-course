## execution

**从本题理解：源代码怎样运行**

“高级语言”描述的是语言抽象层次，“编译”和“解释”描述的是实现程序的执行方式，不能把两者一一对应。编译器可以先把程序翻译成另一种形式，解释器则负责执行相应指令；同一种语言也可以有不同实现。

以常用的 CPython 为例，源代码先编译成字节码，再由解释器执行，因此把 Python 理解成“完全不经过编译”也不准确。`.py` 是源文件扩展名，不是运行结果；终端执行 `python 文件名.py` 时，真正运行程序的是所选 Python 解释器。交互环境会显示裸表达式的值，脚本通常需要 `print()` 才会输出。

继续阅读：[第1章：Python 与运行环境](../topics/chapter-01.md)。

## environment

**从本题理解：解释器、编辑器与版本**

编辑器负责写代码，解释器负责执行代码，二者不是同一个工具。IDLE 将编辑和交互运行放在一起，但保存 `.py` 文件后，也可以从终端调用解释器执行。

同一台电脑可以安装多个 Python 版本。遇到“这里能运行，那里找不到模块”，先确认两个环境使用的解释器是否一致：在交互环境执行 `import sys`，再查看 `sys.executable` 和 `sys.version`。安装第三方包时，`python -m pip` 会使用这个 `python` 对应的环境。开源、免费和跨平台不意味着任意平台的文件路径、系统命令都完全相同。

## paradigm

**从本题理解：程序设计语言的分类**

过程式编程围绕“按什么步骤完成任务”组织函数和语句；面向对象编程把状态与相关操作组织到对象中。它们是组织程序的思路，不是语言只能二选一的标签。

例如计算一组成绩的平均分，可以用函数接收列表并返回结果；管理学生姓名、成绩及相关操作时，也可以设计 `Student` 类。Python 支持过程式、面向对象等多种方式。题目按课程常见分类选择答案时，需要理解分类依据；不能据此推断 Python 程序必须使用类，或 C 语言不能实现复杂的数据抽象。

继续阅读：[第8章：类和对象](../topics/chapter-08.md)。

## hardware

**从本题理解：硬件、软件与存储单位**

硬件是处理器、内存、存储设备等物理部件；软件是让硬件完成任务的程序及相关数据。操作系统属于系统软件，编辑器等工具属于软件，Python 源程序本身也不是硬件。

最小的二进制信息单位是 bit，一个字节 B 通常含 8 bit，因此 2 B 可保存 16 个二进制位。要区分“位数”和“可表示的状态数”：8 bit 有 $2^8=256$ 种组合，无符号整数范围为 0～255，而不是 1～256。字符占几个字节还取决于编码，不能把一个字符直接等同于一个字节。

继续阅读：[第1章：计算机基础](../topics/chapter-01.md)。

## names

**从本题理解：标识符、关键字与内置名称**

入门题中常见的合法名字由字母、数字和下划线组成，不能以数字开头，且区分大小写。`item_1` 与 `_item` 合法；`1item` 不合法；`item-name` 会被当成减法表达式，而不是一个名字。Python 也允许部分 Unicode 字符用于标识符。

还要区分关键字和内置名称：`else`、`for` 是语法保留字，不能作普通变量名；`print`、`list` 不是关键字，给它们赋值在语法上合法，却会遮蔽原有功能。例如 `print=3` 后再执行 `print(5)`，是在调用整数，因而报 `TypeError`。布尔常量必须写作 `True`、`False`，大小写变化后会被当成别的名字。

继续阅读：[第1章：标识符和变量](../topics/chapter-01.md)。

## binding

**从本题理解：变量绑定与对象身份**

把变量理解成“指向对象的名字”，比理解成“永远装着某种类型的盒子”更准确。`x=3` 将名字 `x` 绑定到整数对象；执行 `x=7` 是重新绑定，不是把整数对象 3 修改成 7。类型属于对象，变量可以随后绑定到另一种类型的对象。

`==` 比较值，`is` 比较是否为同一对象，`id()` 给出对象存活期间的身份标识。判断两个数是否相等应使用 `==`，不能依赖小整数缓存或字符串复用造成的 `is` 结果。可变列表的原地修改与名字重新赋值也有区别：前者可能被所有别名观察到，后者只改变当前名字的绑定。

继续阅读：[第3章：赋值与对象引用](../topics/chapter-03.md)。

## encoding

**从本题理解：字符、码点与字节编码**

Unicode 为字符分配码点，例如 `ord('A')` 为 65，`ord('张')` 为 24352；`chr()` 完成反向转换。`U+5F20` 和十进制 24352 表示同一码点，只是记数方式不同。`ord()` 接收单个字符，不能直接把整个多字符字符串转换成一个码点。

UTF-8 则规定如何把码点编码成字节，不能把它和 Unicode 字符集合混为一谈。例如 `len('张')` 为 1，而 `len('张'.encode('utf-8'))` 为 3；前者数 Python 字符串中的码点，后者数字节。ASCII 字符在 UTF-8 中仍占一个字节，这也是英文字符 A 的编码值在本题中保持 65 的原因。

继续阅读：[第1章：字符编码](../topics/chapter-01.md)。

## input

**从本题理解：输入处理的四个步骤**

多项数值输入可按“读整行 → 拆文本 → 逐项转换 → 拆包赋值”理解。输入 `3 5` 时，`input()` 返回 `'3 5'`，`split()` 得到 `['3','5']`，`map(int,...)` 按需将每一项转成整数，最后两个变量分别接收 3 和 5。

```python
line = input()
parts = line.split()
m, n = map(int, parts)
```

`int(parts)` 不会逐项处理，而会因参数是列表而报错。输入 `3,5` 应使用 `split(',')`。拆出的项目数和变量数不匹配会产生 `ValueError`；数字格式非法也会在转换时产生 `ValueError`。处理整行字符串时不要随意 `split()`，否则原有空格结构会丢失。

继续阅读：[第1章：输入及输出函数](../topics/chapter-01.md)。

## output

**从本题理解：输出内容由哪些部分组成**

`print(a,b)` 不是把两个变量原样紧贴输出，而是先将参数转成文本，再用 `sep` 连接，最后加上 `end`。默认 `sep=' '`、`end='\n'`，所以参数间有一个空格，输出后换行。`print(a,b,sep='')` 才是无分隔拼接。

```python
print(5, 9)             # 5 9
print(5, 9, sep='-')    # 5-9
print('*', end=' ')     # 星号后有一个空格，暂不换行
```

判断题和编程题都要检查前导空格、参数间空格、行尾空格与换行。不要给自动评测的输出加入“请输入”等提示语。观察不可见字符时可先构造字符串，再使用 `repr()` 查看其边界；直接看网页中排版后的文字不一定能分辨空格数量。

继续阅读：[第1章：print 与输出格式](../topics/chapter-01.md)。

## comments

**从本题理解：注释与字符串的边界**

英文半角 `#` 在字符串外引出单行注释，从它开始到本行末尾不再作为代码执行。例如 `x=3 # 说明` 中，赋值仍然会执行。全角 `＃` 不是 Python 注释符号。

字符串内部的 `#` 属于普通字符：`print('#')` 会输出井号。判断一段代码时，先确认引号边界，再识别注释，不能看到 `#` 就认为后面全部无效。三引号首先定义的是多行字符串；它在模块、类或函数开头时可以作为文档字符串，不能简单地把所有三引号字符串都称为注释。

继续阅读：[第1章：注释](../topics/chapter-01.md)。

## base

**从本题理解：进制转换与位权**

在基数为 $b$ 的计数制中，各位从右往左的权重依次为 $b^0,b^1,b^2,\ldots$。例如八进制 `35` 是 $3\times8+5=29$，十六进制 `2AC` 是 $2\times16^2+10\times16+12=684$。转换到目标进制时，可反复除以目标基数，并把余数倒序排列。

```python
n = int('2AC', 16)
print(n)          # 684
print(oct(n))     # 0o1254
print(bin(10))    # 0b1010
```

整数对象只保存数值，`0xA` 与 `10` 不是两种整数类型。`bin()`、`oct()`、`hex()` 返回带前缀的字符串，而 `int(文本,基数)` 返回整数；题目只要求数字部分时，不能额外写进制前缀。某基数的合法数码必须小于该基数，例如八进制不能含 8 或 9。

继续阅读：[第1章：数制与进制转换](../topics/chapter-01.md)。

## fractions-base

**从本题理解：整数和小数的进制转换方向不同**

整数部分用“除基取余、逆序排列”；纯小数部分用“乘基取整、顺序排列”。例如 $0.625\times2=1.25$ 取 1，$0.25\times2=0.5$ 取 0，$0.5\times2=1$ 取 1，于是 $0.625=(0.101)_2$。整数 19 是 `10011`，若题目要求整数部分占 8 位，再在左侧补零。

为什么有些小数算不完？一个最简分数能用有限二进制小数表示，当且仅当分母只含质因子 2，例如 $5/8$ 可以，$1/10$ 不可以。因此循环既要判断余数是否归零，也要遵守题目给定位数上限；截断和四舍五入是两种不同要求。精确转换十进制输入时，可用 `Fraction(输入字符串)`，避免先转 `float` 造成近似。

继续阅读：[第1章：数制与进制转换](../topics/chapter-01.md)。

## signed

**从本题理解：固定字长下的原码、反码、补码**

先确定题目规定的字长，再写二进制位。8 位有符号表示中，正数的原码、反码和补码相同，最高位为 0；负数的原码将最高位置 1，反码保留符号位并翻转其余位，补码在反码基础上加 1。

以 -78 为例：正数 78 是 `01001110`，负数原码 `11001110`，反码 `10110001`，补码 `10110010`。也可用 $2^8-78=178$ 验证其补码位型。8 位补码范围为 -128～127，不能把任意大整数强行塞进 8 位。Python 的 `int` 不固定为 8 位；本题的字长来自表示要求，而不是 Python 整数的实际存储大小。

继续阅读：[第1章：原码、反码、补码](../topics/chapter-01.md)。

## conversions

**从本题理解：文本形式与数值类型转换**

`input()` 的结果永远先是字符串。`int('10')` 解析整数文本，`float('10.0')` 解析浮点文本，`str(10)` 则生成数值的字符串形式。`int('10.0')` 不会先自动转成浮点数，因此报 `ValueError`；`int(10.9)` 则接收数值并向零截断，得到 10。

```python
a = 3
print('a' * 2)         # aa：引号里是字母，不是变量
print(str(a) * 2)      # 33：先取变量值，再转字符串
print(int('11', 2))    # 3：以二进制解析
```

要分清错误种类：传入不支持的对象类型通常是 `TypeError`，支持的类型中内容不合法通常是 `ValueError`。也不要用 `int(float(文本))` 盲目修补输入，它会丢掉小数部分；题意要求保留小数时应直接使用 `float()`。

继续阅读：[第2章：内置转换函数](../topics/chapter-02.md)。

## numeric

**从本题理解：运算符决定值，也影响结果类型**

`int` 表示整数，`float` 表示浮点数，`complex` 表示复数，`bool` 是整数类型的子类。整数与浮点数进行常见算术运算时，结果通常转为浮点数；`/` 即使两侧都是整数，也执行普通除法，例如 `1/2` 为 `0.5`、`4/2` 为 `2.0`。

`//` 向负无穷取整，不是简单删除小数：`-3//2` 为 -2，而 `int(-3/2)` 为 -1。对于正除数，余数满足 `a == (a//b)*b + a%b`。`32.2//6` 的值虽然是整数大小的 5，但类型仍为 `float`，打印成 `5.0`；判断输出时必须同时跟踪数值与类型。

继续阅读：[第2章：数字类型](../topics/chapter-02.md)。

## precedence

**从本题理解：优先级、结合方向与一元运算**

计算表达式时先列出括号，再处理乘方、乘除与整除求余、加减，最后处理比较和逻辑运算。同一层大多从左到右，但乘方从右向左结合：`3**2**3` 是 `3**(2**3)`，不是 `(3**2)**3`。

乘方与负号相邻时需特别注意：`-2**4` 是 `-(2**4)=-16`，`(-2)**4` 才是 16；右侧指数可以写负号，如 `2**-2=0.25`。Python 没有 `++` 自增运算，`++i` 只是两次一元正号，`--i` 是两次一元负号，都不会更新变量；真正增加 1 应写 `i+=1`。不要把其他语言的符号含义直接套到 Python。

继续阅读：[第2章：数字运算与语句](../topics/chapter-02.md)。

## truth

**从本题理解：布尔对象与“真假性”**

`True` 和 `False` 是布尔常量，转换成整数分别为 1 和 0。条件判断却不要求表达式本身一定是布尔对象：数值 0、`None`、空字符串及空容器是假值，大多数其他对象是真值。例如 `bool([])` 为假，而 `bool([0])` 为真，因为后者并不为空。

要区分 `False` 与字符串 `'False'`：后者有 5 个字符，是真值。同样，`0 == False` 为真不意味着它们类型相同，`type(0)` 为 `int`，`type(False)` 为 `bool`。未定义的名字 `FALSE` 会先触发 `NameError`，程序根本还没进入真假转换阶段。`None` 的判断通常写 `x is None`，用于区分“没有值”和合法的数值 0。

继续阅读：[第2章：布尔类型与空值](../topics/chapter-02.md)。

## short-circuit

**从本题理解：短路求值不是只算 True 或 False**

`x and y` 先检查 `x`：若它是假值，直接返回 `x`；否则继续求值并返回 `y`。`x or y` 则在 `x` 为真值时直接返回 `x`，否则返回 `y`。它们返回的是操作数，所以 `3 and 0 and 5` 返回整数 0，`True and 2` 返回整数 2。只有 `not` 总返回布尔值。

```python
print(0 and 1 / 0)     # 0：右侧根本不执行
print('' or 'default') # default
print(not [])         # True
```

长表达式先算算术和比较，再按 `not`、`and`、`or` 的优先级组合；建议在纸上标出每个子式的值与类型。短路也常用于保护操作，例如 `n != 0 and total/n > 2`。用 `x or 默认值` 时要确认 0、空串等合法输入是否也应被替换，不能把它等同于“只有 None 才替换”。

继续阅读：[第2章：逻辑运算](../topics/chapter-02.md)。

## assignment

**从本题理解：赋值、表达式与拆包顺序**

普通 `=` 是赋值语句，不是比较运算 `==`，不能直接嵌入 `x=(y=z+1)+1` 这种表达式。若两个名字都要接收同一个结果，可写 `x=y=z+1`。`i*=3+5` 要先求出整个右侧，数值情形下相当于 `i=i*(3+5)`，不是 `i=i*3+5`。

拆包赋值先求整个右侧，再从左到右赋给各目标。若旧 `t=1`，`t,a=2,t+1` 先得到右侧 `(2,2)`，所以 `a=2`；交换 `a,b=b,a` 也利用此规则。右侧必须可迭代且元素数量匹配：整数 34 不能直接拆成 3 和 4，字符串 `'3 4'` 则有 3 个字符，而不是两个数。

继续阅读：[第2章：赋值与拆包](../topics/chapter-02.md)。

## types-add

**从本题理解：同一个运算符对不同类型有不同含义**

对数字，`+` 表示加法；对字符串，表示拼接；对列表，表示连接两边的元素。例如 `2+3` 为 5，`'2'+'3'` 为 `'23'`，`[2]+[3]` 为 `[2,3]`。Python 不会为了完成拼接自动把整数变成字符串，所以 `'age'+23` 在运行时产生 `TypeError`。

若要拼接，使用 `'age'+str(23)` 或 `f'age{23}'`；若要计算，使用 `int('23')+1`。二者目的不同，不能随意选择一种转换。还要把语法阶段和执行阶段分开：正常引号下的字符串加整数，能通过语法解析；弯引号 `“ ”` 不是 Python 字符串定界符，原样输入会先出现语法错误。

继续阅读：[第2章：字符串与类型转换](../topics/chapter-02.md)。

## complex

**从本题理解：复数的表示、属性与模**

Python 使用 `j` 或 `J` 表示虚数单位，例如 `1J`、`3+4j` 都是复数。实部和虚部分别由 `.real`、`.imag` 读取，返回浮点数；`.conjugate()` 返回共轭复数。必须调用方法才能得到结果，不能把 `.conjugate` 方法对象当成计算后的值。

```python
z = 3 + 4j
print(z.real, z.imag)  # 3.0 4.0
print(z.conjugate())   # (3-4j)
print(abs(z))          # 5.0
```

复数的绝对值是模，按 $\sqrt{a^2+b^2}$ 计算，不是分别把实部虚部取绝对值。复数不能用 `<`、`>` 排大小；普通数值比较的结果才是布尔值。复数字面量中数字和 `j` 要连写，概念公式 `a+bj` 也不能直接替代变量运算 `complex(a,b)`。

继续阅读：[第2章：数字类型](../topics/chapter-02.md)。

## math

**从本题理解：数学公式如何翻译成 Python**

先识别公式的运算结构，再选择函数。平方根用 `math.sqrt()`，自然对数用 `math.log()`，指数 $e^x$ 用 `math.exp()`；乘法必须明确写 `*`，分式的分子、分母需要分别加括号。`sqrt(4)` 返回 `2.0`，所以后续乘积可能是浮点数而不是整数。

三角函数参数以弧度为单位，角度先用 `math.radians()` 转换。还要检查定义域：实数平方根的参数不能为负，自然对数参数必须大于 0，分母不能为 0。输出格式化只控制最后显示多少位，并不修复公式、定义域或中间计算的错误。`ceil()` 向上取整，`floor()` 向下取整，均与向零截断的 `int()` 有区别。

继续阅读：[第2章：math 库](../topics/chapter-02.md)。

## string-model

**从本题理解：字符串是不可变的字符序列**

Python 没有单独的内置 `char` 类型，`'A'` 是长度为 1 的 `str`。字符串支持索引、切片、遍历、成员判断与长度查询，但不支持 `s[0]='B'` 这样的原地修改。要更改字符，可构造新字符串并重新赋值，例如 `s='B'+s[1:]`。

字符串的长度由对象记录，不依赖 `\0` 作为结束标志；`len('a\0b')` 为 3，中间的空字符也计入长度。`list('abc')` 会遍历字符串，生成 `['a','b','c']`；`['abc']` 则只含一个完整字符串。这个区别也适用于拆包和 `extend()`：传入字符串时，它通常被当成可逐字符遍历的序列。

继续阅读：[第3章：序列与字符串](../topics/chapter-03.md)。

## escapes

**从本题理解：源码写法与实际字符串并不相同**

普通字符串中的反斜杠引出转义，例如 `\n` 是一个换行符、`\t` 是一个制表符，`\\` 才是一个真实反斜杠。因此 Windows 风格路径中的 `\test` 如果直接写进普通字符串，开头的 `\t` 会被解释成制表符，打印结果就改变了。

```python
path = r'smith\exam1\test.txt'
print(path)
print(len('\t'))   # 1：一个制表符
print(len('\\t'))  # 2：反斜杠和字母 t
```

`r` 前缀可以减少路径中的转义处理，但原始字符串也有语法限制，例如不能以奇数个反斜杠紧接结束引号。查看 `repr(path)` 会得到便于观察转义的表示，不能把其中为展示而写出的双反斜杠误认为实际内容里有两个反斜杠。

继续阅读：[第2章：字符串类型](../topics/chapter-02.md)。

## slicing

**从本题理解：索引、切片与负步长**

索引 `a[i]` 取得一个元素，下标从 0 开始，负下标从尾部计数，`-1` 是最后一个元素。切片 `a[start:stop:step]` 取得一个新序列：从起点开始，每次前进步长，只要还没到终点就继续，终点本身不取。正步长时可用 `range(start,stop,step)` 列出目标下标。

```python
a = [10, 20, 30, 40, 50]
print(a[1:5:2])  # [20, 40]：下标 1、3
print(a[:-1])    # [10, 20, 30, 40]
print(a[::-1])   # [50, 40, 30, 20, 10]
```

切片越界会裁剪到合法边界，而单个索引越界会报错。负步长时默认起点和终点随方向改变，`a[::-1]` 的省略终点不等于显式写 `a[-1:-1:-1]`；后者是空列表。步长不能为 0。列表切片是浅拷贝，外层新建，内部可变对象仍可能共享。

## mutability

**从本题理解：原地修改与生成新对象**

列表是可变对象，能原地修改元素或增删；字符串、元组不能更改自身位置上的引用。`s=s+'x'` 虽然能执行，但它创建新字符串并让名字 `s` 重新绑定，不能证明字符串可变。元组里的列表仍可改变，如 `t=([1],)` 后执行 `t[0].append(2)` 合法。

另一个常考区别是返回值：`a.sort()`、`a.reverse()`、`a.append(x)` 修改列表并返回 `None`；`sorted(a)`、`a[::-1]` 返回新列表。因此 `b=a.sort()` 后 `b` 不是已排序列表，而是 `None`。阅读代码时分别记录“原对象现在是什么”和“表达式返回了什么”，就能避免把二者混为一谈。

继续阅读：[第3章：列表修改与返回值](../topics/chapter-03.md)。

## copying

**从本题理解：赋值、浅拷贝和深拷贝**

`b=a` 只复制引用，两个名字指向同一个列表；`b=a[:]`、`b=a.copy()` 新建外层列表，但其中的元素仍指向原对象。浅拷贝后，给一个位置重新赋值通常只影响所在的外层列表，修改共享的内部列表则会被两边看到。

```python
a = [[1], 2]
b = a.copy()
b[0].append(3)
print(a)          # [[1, 3], 2]：内部列表共享
b[1] = 9
print(a[1])       # 2：外层位置独立
```

需要递归复制内部可变对象时可使用 `copy.deepcopy()`。`==` 比较内容，`is` 比较身份，因此浅拷贝后可以同时满足 `a == b` 和 `a is not b`。判断一道题是否会“跟着改变”，关键是找到真正被修改的对象，而不是只看变量名是否不同。

继续阅读：[第3章：赋值、浅拷贝与嵌套引用](../topics/chapter-03.md)。

## repeat

**从本题理解：序列重复与内部引用共享**

字符串或列表乘整数表示重复，不是把内容解释成数值。`'23'*3` 为 `'232323'`，`[4,5]*3` 为 `[4,5,4,5,4,5]`，不会自动生成三个子列表。字符串原有的空格也会一起重复，所以 `'12 '*3` 在最后仍有一个空格。

若元素本身是可变列表，重复操作复制的是引用：`rows=[[0]*2]*3` 中三行是同一个对象，执行 `rows[0][0]=1` 会让三行都改变。要创建独立的行，应写 `rows=[[0]*2 for _ in range(3)]`。同样，列表 `+` 只连接一层，`[1,2]+[[3]]` 得到 `[1,2,[3]]`，不会递归展开内部列表。

继续阅读：[第3章：序列运算与嵌套引用](../topics/chapter-03.md)。

## search

**从本题理解：查存在、查位置与查全部匹配**

只判断有无时使用 `x in seq`，结果为布尔值。字符串 `find()` 返回第一次匹配的起始下标，找不到返回 -1；字符串和列表的 `index()` 也查首次位置，但找不到会引发 `ValueError`。列表没有 `find()` 方法。

```python
s = 'programming'
print(s.find('r'))      # 1
print(s.find('r', 2))   # 4：从下标 2 开始找
print('x' in s)         # False
```

不能写 `if s.find(x)` 判断存在：找到在下标 0 时是假值，没找到的 -1 反而是真值。应写 `if x in s` 或 `if s.find(x) != -1`。题目要求输出所有匹配位置时，需要遍历下标或重复搜索，而不是只调用一次查找；要求倒序位置时还需改变遍历方向。

继续阅读：[第3章：字符串使用](../topics/chapter-03.md)。

## chained

**从本题理解：链式比较会复用中间操作数**

`a < b < c` 按逻辑可理解为 `a < b and b < c`，并不是先把 `a < b` 的布尔值拿去与 `c` 比较。成员运算 `in` 也属于比较运算，所以 `'34' in '1234' == True` 中，中间操作数是字符串 `'1234'`，后一项比较的是 `'1234' == True`，结果为假。

加括号会改变分组：`('34' in '1234') == True` 先得到成员判断结果，因此为真。实际编程中直接写 `'34' in '1234'` 更清楚。链式比较还具有短路特性，前一项为假时不再计算后项；遇到混合比较符号时，把它拆成相邻两项的比较，再逐项分析最可靠。

继续阅读：[第4章：条件语句](../topics/chapter-04.md)。

## join

**从本题理解：连接字符串与空格精确比较**

`分隔符.join(各字符串)` 只在相邻项之间放分隔符，不会自动在首尾添加。例如 `' '.join(['12','12','12'])` 为 `'12 12 12'`，而 `'12 '*3` 为 `'12 12 12 '`，末尾多一个空格，比较结果为假。

```python
parts = ['12', '12', '12']
s = ' '.join(parts)
print(repr(s))         # '12 12 12'
print(len(s))          # 8
```

`join()` 的元素必须是字符串，数值列表先用 `map(str,values)` 转换。`strip()` 能改变两端空白，但不能为了解决输出问题随意使用：若空格属于题目要求，去掉它就是改变答案。比较字符串时，先写出每一段内容和长度，再叠加 `print()` 自带的 `sep`，能更准确地定位多余空格。

## split

**从本题理解：指定分隔符与默认拆分不同**

`split('/')` 把每一个 `/` 都视为分界，连续分隔符之间会产生空字符串，首尾分隔符也会产生空项。因此 `'3//11//2018'.split('/')` 有 5 项，两个空字符串也各算一个列表元素。

```python
print('a,,b,'.split(','))  # ['a', '', 'b', '']
print('  a   b  '.split()) # ['a', 'b']
print(''.split(','))      # ['']
print(''.split())         # []
```

不带参数的 `split()` 按连续空白拆分，合并空白并忽略两端空白，这与显式 `split(' ')` 也不同。选择方式取决于数据格式：普通空格分隔数值通常用 `split()`；CSV 式的空字段若有意义，就不能先合并分隔符。`len()` 数的是结果中的元素，而不是非空元素。

继续阅读：[第3章：字符串使用](../topics/chapter-03.md)。

## strip

**从本题理解：清理哪一端，保留哪些字符**

`strip()` 清理两端空白，`lstrip()` 仅清理左端，`rstrip()` 仅清理右端；它们都返回新字符串，保留中间空格。默认空白还包括制表符、换行符，而 `lstrip(' ')` 明确只清理普通空格。题目要求保留尾部空格时，不能用 `strip()` 替代单侧处理。

传入参数时，它表示“可被清理的字符集合”，不是一个固定前缀或后缀。例如 `'abbaXba'.strip('ab')` 得到 `'X'`，因为两端连续的 a、b 都被去掉。若只想删除一个完整前缀，可用 `removeprefix()`。输出多个清理结果时，别忘了 `print()` 默认还会在参数之间加一个空格，应把清理后的内容与输出分隔符分开计算。

继续阅读：[第3章：字符串使用](../topics/chapter-03.md)。

## format

**从本题理解：格式规格由填充、对齐、宽度和类型组成**

常见结构为 `[[填充字符]对齐方式][宽度][.精度][类型]`。`<` 左对齐、`>` 右对齐、`^` 居中；字符串默认左对齐，数值默认右对齐。宽度是最小宽度，不会截断过长内容。`d` 用于十进制整数，`s` 用于字符串，`.2f` 表示小数点后保留两位。

```python
print(f'|{"this":8s}|') # |this    |
print(f'|{1234:8d}|')   # |    1234|
print(f'{31:08b}')      # 00011111
print(f'{"11":0>5s}')  # 00011
```

先算内容本身长度，再用字段宽度减去它，才知道补几个字符。动态宽度应显式写成 `f'{s:^{width}}'`，格式串里的普通字母不会自动读取同名变量。浮点格式化的宽度还包含符号和小数点，精度不等于总字符数。

继续阅读：[第2章：格式化输出](../topics/chapter-02.md)。

## format-args

**从本题理解：格式串中的占位符怎样取值**

`str.format()` 的位置参数编号从 0 开始，编号与占位符出现顺序可以不同。`'{1}+{0}={2}'.format(2,3,5)` 先得到三个参数 2、3、5，再按编号替换，输出 `3+2=5`。同一个参数也可以多次引用。

命名占位符需要显式传参，例如 `'{first}-{second}={0}'.format(11,first=34,second=23)`。花括号外的减号与等号只是文本，不会再执行运算；花括号里的 `first` 也不会自动去局部变量中查找。f-string 则可直接写表达式，如 `f'{a}-{b}={a-b}'`。分清这两种机制，就不会把字符串里的算式误认为真正参与计算的代码。

继续阅读：[第2章：格式化输出](../topics/chapter-02.md)。

## rounding

**从本题理解：浮点近似与最终显示**

多数十进制小数不能被二进制浮点数精确表示，计算机保存的是附近的可表示值。因此 `round()` 或 `.2f` 格式化所处理的，可能并不是纸面上那个精确的十进制数。遇到 14.345 一类边界值，不能机械地按十进制“第三位是 5”判断结果。

即使没有表示误差，Python 的 `round()` 在恰好居中时也采用向偶数舍入，而不是一律进位：`round(2.5)` 为 2，`round(3.5)` 为 4。格式化返回字符串，`round(x,2)` 返回数值，不保证显示末尾的零。若业务要求精确十进制及指定舍入规则，应从原始文本构造 `Decimal` 并明确舍入方式；不要先转成 `float` 再期望恢复精确输入。

继续阅读：[第2章：数字类型与格式化输出](../topics/chapter-02.md)。

## methods

**从本题理解：取得方法与执行方法是两回事**

`c.lower` 取得绑定到对象 `c` 上的方法对象，`c.lower()` 才真正调用它并返回小写字符串。打印方法对象会得到方法描述，不能当成转换结果。字符串不可变，因此 `lower()` 不会改变原对象，若要保存结果需写 `c=c.lower()`。

```python
c = 'AbC'
result = c.lower()
print(c)          # AbC：原值不变
print(result)     # abc
print(c.isalpha())# True
```

`isdigit()`、`isalpha()`、`isalnum()` 检查整个字符串是否非空且每个字符都满足相应类别；空串的这几种判断为假。它们按 Unicode 规则工作，不只接受 ASCII 字符。题目严格要求英文字母或十六进制字符时，应按明确范围判断，不能直接把“属于字母数字”当成“合法十六进制数码”。

继续阅读：[第3章：字符串方法](../topics/chapter-03.md)。

## list-methods

**从本题理解：列表方法按“位置”还是“值”操作**

`append(x)` 把 x 作为一个整体追加，`extend(items)` 把可迭代对象逐项追加，`insert(i,x)` 在位置 i 前插入。删除时，`remove(x)` 删除第一个值等于 x 的元素，不返回被删元素；`pop(i)` 按下标删除并返回元素，省略下标则处理最后一项。

```python
a = [3, 4, 3]
a.remove(3)
print(a)       # [4, 3]：只删首个 3
print(a.pop()) # 3
print(a)       # [4]
```

元素删除后，右边元素的下标会前移；跟踪程序时每一步都应写出新的列表。`append()`、`remove()`、`sort()` 等修改列表后返回 `None`，不能把它们的返回值再赋给列表变量。`pop()` 则特意返回被删元素，是这一组题里很容易混淆的差别。

继续阅读：[第3章：列表修改与返回值](../topics/chapter-03.md)。

## sorting

**从本题理解：排序的对象、顺序与返回值**

`sorted(items)` 返回新的已排序列表，原对象不变；`a.sort()` 原地修改列表并返回 `None`。要降序使用 `reverse=True`。`max()` 只取最大元素，不返回排序后的完整序列，空序列且无默认值时还会报错。

排序前先确定按什么比较：整数 `[2,10]` 排成 `[2,10]`，字符串 `['2','10']` 则排成 `['10','2']`。若题意是按数值大小，必须先转成数值再排序，最后再转回字符串用于输出。`random.shuffle(a)` 也原地修改列表并返回 `None`，但它是打乱，不是排序；不要写 `a=random.shuffle(a)`。

继续阅读：[第3章：列表方法](../topics/chapter-03.md)与[第4章：搜索和排序](../topics/chapter-04.md)。

## random

**从本题理解：随机区间的端点**

`random.random()` 返回满足 $0\le x<1$ 的随机浮点数；对非负值使用 `int()` 相当于向下取整，所以题目中的 `int(x*90)+10` 按区间分析得到 10～99。直接取整数时，`randint(10,99)` 包含两个端点，`randrange(10,100)` 不包含右端。

```python
import random
n = random.randint(10, 99)
items = [1, 2, 3]
random.shuffle(items)  # 原地打乱，返回 None
```

区间题先写原始范围，再依次做乘法、取整和平移，不要只试几个随机样本来猜端点。随机运行未碰到某个边界，不代表边界不可能出现；`seed()` 用于帮助复现实验序列，也不改变这些函数约定的区间。

继续阅读：[第3章：random 库](../topics/chapter-03.md)。

## iteration

**从本题理解：遍历元素、遍历下标与拆包**

`for row in students` 每次拿到一整行，`row[0]` 再访问其中第一个字段；`for number,name in students` 则要求每行恰好有两个元素，并直接拆包。二维访问 `students[i][j]` 是先选第 i 行，再选该行第 j 项，不是同时对一个平面下标取值。

```python
students = [(1001, '张三'), (1002, '李四')]
for index, (number, name) in enumerate(students):
    print(index, number, name)
```

只需要内容时直接遍历元素；还需要下标时使用 `enumerate()`；需要特定方向或步长时再遍历 `range()`。拆包不会自动转换类型，字符串拆包得到的仍是字符。也尽量避免用 `id`、`list` 等内置名称命名变量，防止遮蔽其功能。

## aggregate

**从本题理解：计数、求和、平均值与最值累积**

`len()` 数元素个数，`sum()` 累加数值，平均值是 `sum(values)/len(values)`。Python 3 的 `/` 返回普通除法结果，因此 25 除以 5 输出 `5.0`；换成 `//` 会改变含义，不能为了输出没有小数点就随意换运算符。空序列需要先处理，避免除以 0。

逐项统计可维护一个累积量：求和从 0 开始；计数遇到匹配加 1；求非负长度最大值可从 0 开始，再令 `longest=max(longest,当前长度)`。每次循环结束后，这个变量都应该代表“已经处理过的所有数据”的统计结果。比较是否高于平均值时，也可比较 `x*人数 > 总和`，避免不必要的浮点除法。

## range

**从本题理解：range 的边界与循环结束状态**

`range(start,stop,step)` 包含起点，不包含终点；正步长要求当前值小于终点，负步长要求当前值大于终点。因此 `range(10,0,-2)` 是 10、8、6、4、2。若需要正向包含 n，常写 `range(1,n+1)`。步长为 0 会报错。

`for` 每次从可迭代对象取下一项，再赋给循环变量，结束时不会额外执行一次加减。循环体若未重赋该变量，非空遍历结束后它保留最后取到的值。空范围一次也不执行，若变量此前未定义，循环后访问它会报错。分析图形或序列和题时，先把小规模的取值逐个列出，再检查首项、末项和步长，能有效避免多算或少算一项。

## bitwise

**从本题理解：按位运算与数位统计**

先把整数对齐为二进制位，再逐位计算：`&` 仅在两位都为 1 时得 1，`|` 有一位为 1 就得 1，`^` 仅在两位不同时得 1。因此 `x^y` 中的 1 的个数，就是两个非负整数二进制表示的不同位数。`^` 不是乘方，乘方要写 `**`。

负整数按符号扩展的补码语义处理，可以选足够宽的位数手算，但不能把最高位截掉后当成无符号数。取反满足 `~x == -x-1`，例如 `~9=-10`。统计二进制 1 的数量可用 `bin(n).count('1')`，而统计总位数时，0 和负数的符号、前缀需要另行分析。本节按课程范围说明保留，不代表新增考试要求。

继续阅读：[第2章：位运算](../topics/chapter-02.md)。

## import

**从本题理解：导入语句把什么名字放入当前作用域**

`import math` 绑定模块名 `math`，通过 `math.sqrt()` 使用；`import math as t` 绑定名字 `t`，通过 `t.sqrt()` 使用，不会同时额外创建 `math` 名字；`from math import sqrt` 则直接绑定函数名 `sqrt`。判断代码能否执行时，先看当前到底定义了哪个名字。

导入本身是可执行语句，不强制必须在第一行，但调用模块功能前必须已执行，并且名字在当前作用域可见。通常把导入集中在文件开头，是为了便于阅读和管理依赖。别名只改变访问名称，不改变函数含义，例如 `t.sin()` 的参数仍然是弧度，不会因为使用别名就变成角度。

## branches

**从本题理解：两个 if 与 if-elif 的执行差别**

连续的两个 `if` 会分别判断，前一个分支修改变量后，后一个条件看到的是新值。`if-elif-else` 则只选择第一个满足条件的分支，选中后不再判断后续分支。因此先把大写改小写、再独立判断是否小写并改大写，会把原本大写的字符转换两次。

```python
c = 'A'
if c.isupper():
    c = c.lower()
if c.islower():
    c = c.upper()
print(c)  # A
```

若目的是互换大小写，应让两个分支互斥，或直接用 `swapcase()`。分段函数、计费与输入校验也需要先决定分支是否互斥，并明确边界上的等号归哪一段，避免同一个输入被重复处理或遗漏。

继续阅读：[第4章：条件语句](../topics/chapter-04.md)。

## filtering

**从本题理解：筛选条件与保留内容应分开设计**

字符串处理通常分三步：逐字符检查条件、保留需要的字符、用 `join()` 组成结果。用于判断的标准化形式不一定就是输出形式。例如不区分大小写地去重，可以用 `c.lower()` 判断是否见过，却把原字符 `c` 放进结果，这样能保留首次出现的大小写。

```python
text = 'A1-b2!'
clean = ''.join(c.lower() for c in text if c.isalnum())
print(clean)  # a1b2
```

先确认题目允许哪些字符：`isalnum()` 包括 Unicode 字母数字，十六进制则只能从 `0123456789abcdefABCDEF` 选择。还要明确空结果如何处理、是否保留空格、比较是否区分大小写。不要为简化代码而擅自删除题目没有要求忽略的字符。

继续阅读：[第3章：字符串使用](../topics/chapter-03.md)。

## counting

**从本题理解：存在性、出现次数与字符多重集合**

“是否出现”用成员判断，“出现几次”需要计数，“字符和次数都一致”则需要比较多重集合。比如 `'aab'` 与 `'abb'` 的字符集合相同，但不是变位词，因为 a、b 的次数不同；排序后比较或 `collections.Counter` 才能保留次数信息。

去重又是另一种任务：集合可以快速记录见过的字符，但直接转集合不能保留原输入顺序。需要保序时，遍历原序列，用集合判断是否首次出现，再追加到结果。统计两个字符串共有多少字符前，也要看题目保证哪一边不重复；遍历重复的一边可能把同一个字符多算。大小写、空格、标点是否参与比较，都必须由题意决定。

继续阅读：[第5章：集合、字典与字符计数](../topics/chapter-05.md)。

## patterns

**从本题理解：把图形拆成行号和行内规律**

先确定第 i 行由哪几段组成，再决定循环。星号三角形常见规律是第 i 行有 i 个星号；等腰数字图形则可以拆成左侧空格、递增段和递减段。最高值只出现一次，所以递减段从 i-1 开始，而不是再次从 i 开始。

假设所有数字都占一个字符，峰值为 i 的回文数字行宽为 `2*i-1`，最终行峰值为 n，则左侧空格数是 n-i。若数字可能达到两位，必须重新核对题目限制和实际字符宽度，不能继续套单字符公式。输出前用小输入手算每行的前导空格、分隔符、行尾空格和换行；不要用网页里看起来相近的形状替代精确字符比较。

## rational

**从本题理解：求和、精确分数与取整时机**

序列求和先把“第 i 项”写清楚，再确定 i 的起止和步长。交错符号常用 `(-1)**(i-1)`，从第 1 项开始为正；分母若为连续奇数，可写 `2*i-1`。取整应按题意在整个和算完之后执行，通常不能把每项先取整再相加。

`floor()` 向负无穷取整，`ceil()` 向正无穷取整，`int()` 向零截断，三者不同。含分数的和若要求准确判断整数边界，可用 `Fraction(1,分母)` 累加，避免浮点误差使最终取整偏差。还要区分“向下取整”和“严格小于原数的最大整数”：当原数本身为整数时，后者比前者少 1，必须根据题目提示说明采用哪种定义。
