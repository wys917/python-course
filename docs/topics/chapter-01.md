## 1.1 计算机基础

### 计算机特点与系统组成

计算机按程序处理数据，具有运算速度快、精度高、存储和逻辑判断能力强的特点。计算结果仍取决于输入数据、算法及数值表示方式。

计算机系统由**硬件和软件**组成。硬件包括运算器、控制器、存储器、输入设备和输出设备；软件包括系统软件和应用软件。操作系统负责管理硬件和软件资源，常见系统有 Windows、macOS、Linux。

| 单位 | 含义 | 常用换算 |
| --- | --- | --- |
| bit（位） | 一个二进制位，值为 0 或 1 | 最小的信息单位 |
| B（字节） | 8 个二进制位 | 1 B = 8 bit |
| KiB、MiB、GiB | 二进制容量单位 | 每相邻单位相差 1024 倍 |
| KB、MB、GB | 十进制容量单位 | 每相邻单位相差 1000 倍 |

课程题目若采用 1 KB = 1024 B 等习惯约定，按题目约定计算。

### 数制与进制转换

R 进制采用 R 个数码，逢 R 进 1。第 i 位的权为 $R^i$，小数点后依次为 $R^{-1},R^{-2},\ldots$。

$$
(19.625)_{10}=(10011.101)_2
$$

- 十进制整数转二进制：反复除以 2，**倒序**取余数。
- 十进制小数转二进制：反复乘以 2，**顺序**取整数部分；余数为 0 时结束，否则按要求截断。
- 二进制转八进制：从小数点向两侧每 3 位分组，不足补 0。
- 二进制转十六进制：每 4 位分组。

Python 的整数前缀与转换函数：

```python
print(0b1010, 0o35, 0x2AC)  # 10 29 684
print(bin(19))             # 0b10011
print(oct(684))            # 0o1254
print(hex(684))            # 0x2ac
print(int('1010', 2))      # 10
```

`bin()`、`oct()`、`hex()` 返回带前缀的字符串；`int(s, base)` 将指定进制的字符串转为整数。`bin()` 不接受浮点数，小数转二进制需另行处理。

### 原码、反码、补码

以下按 **8 位有符号整数**讨论，最高位为符号位。

| 数值 | 原码 | 反码 | 补码 |
| --- | --- | --- | --- |
| 106 | 01101010 | 01101010 | 01101010 |
| -78 | 11001110 | 10110001 | 10110010 |

正数三种表示相同；负数反码保持符号位、其余位取反，补码为反码加 1。8 位补码范围为 $-128\sim127$。固定宽度补码加法超出最高位的进位丢弃。Python 的 `int` 不限定为 8 位，不能将这套固定宽度范围直接套用到所有 Python 整数。

### 字符编码

ASCII 为基本英文字符分配编码；Unicode 为字符分配码点；UTF-8 将 Unicode 编码为字节序列，每个 Unicode 标量值使用 1～4 字节。ASCII 字符在 UTF-8 中使用同样的单字节表示。

```python
print(ord('A'))                 # 65
print(chr(65))                  # A
print(ord('张'))                # 24352
print('中'.encode('utf-8'))      # b'\xe4\xb8\xad'
```

`ord()` 接受长度为 1 的字符串；`chr()` 由码点生成字符。字符个数与编码后的字节数不是一回事。

### 程序设计语言

机器语言直接使用机器指令；汇编语言使用助记符；高级语言更接近人的表达。高级语言可以通过编译、解释或两者结合执行。CPython 通常先编译为字节码，再由解释器执行，不能说所有高级语言都只能解释执行。

## 1.2 Python语言简介

Python 是跨平台、开源、免费的动态编程语言，支持面向对象等编程方式。程序源文件通常使用 `.py` 扩展名。不同 Python 版本可以在同一台计算机上共存，运行时需选对解释器。

## 1.3 Python IDLE开发环境

可在交互式解释器中逐条执行表达式，也可以把代码保存为脚本运行。IDLE、Thonny、PyCharm 和 Jupyter 都可用于学习；课件推荐 Thonny。

```python
# 保存为 hello.py
print('Hello, Python!')
```

终端中执行 `python hello.py` 或 `python3 hello.py`。IDLE 编辑器中保存文件后使用 Run Module。代码中的引号应使用英文半角引号。

## 1.4 标识符和变量

标识符通常由字母、数字和下划线组成，不能以数字开头，区分大小写；`if`、`else`、`for` 等关键字不能作变量名。Python 也支持符合 Unicode 标识符规则的非 ASCII 名称。

```python
student_count = 30
_item = 5
# 2you = 1      # 不能以数字开头
# else = 1      # 不能使用关键字
```

变量是名称与对象的绑定。赋值不等于复制对象，重新赋值也不等于原地修改对象。

```python
a = [1, 2]
b = a
a.append(3)
print(b)          # [1, 2, 3]
print(a is b)     # True
```

`id(obj)` 获取对象身份标识；`is` 判断是否同一对象；`==` 比较值。`x=3` 后再执行 `x=7`，是把 `x` 绑定到另一个整数对象。不要把 `print`、`input`、`list` 等内置名称作为变量名，否则会遮蔽对应功能。

## 1.5 输入及输出函数

### 注释

`#` 开始单行注释，字符串内部的 `#` 是普通字符。

### input 与类型转换

`input()` 返回字符串，并去掉行末换行符，保留其他空格。需要数值时显式转换。

```python
# 输入一行，例如：3 5
m, n = map(int, input().split())
print(m + n)
```

`split()` 拆分输入，`map(int, ...)` 逐项转整数，最后拆包赋值。`int(input().split())` 错在试图把整个列表转为一个整数。`int('10.0')` 也会报错，读取小数用 `float()`。

### print 与输出格式

```python
print(3, 5)                 # 3 5
print(3, 5, sep=',')        # 3,5
print('A', end=' ')
print('B')                  # 与上一句合起来输出 A B
```

`sep` 默认是一个空格，`end` 默认是换行。在线判题时不要额外输出输入提示语，输出内容和空格按题目要求处理。
