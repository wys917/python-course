:::: question judgment-1 | Q01. 判断题

<div class="section-label">题干 <span>QUESTION</span></div>

 `'age'+23` 不是正确的表达式。

::: answer

T（正确）。

:::

::: explanation

`'age'` 是字符串，`23` 是整数。`+` 用于字符串拼接时，两边都必须是字符串，Python 不会自动把整数转换成字符串，因此执行时会引发 `TypeError`。

这里考查**数据类型与显式转换**：`'age'+str(23)` 得到 `'age23'`；`int('23')+1` 得到整数 `24`。注意：`'age'+23` 本身没有语法错误，错误发生在运行时。

<!-- teaching-notes:start -->

**从本题理解：同一个运算符对不同类型有不同含义**

对数字，`+` 表示加法；对字符串，表示拼接；对列表，表示连接两边的元素。例如 `2+3` 为 5，`'2'+'3'` 为 `'23'`，`[2]+[3]` 为 `[2,3]`。Python 不会为了完成拼接自动把整数变成字符串，所以 `'age'+23` 在运行时产生 `TypeError`。

若要拼接，使用 `'age'+str(23)` 或 `f'age{23}'`；若要计算，使用 `int('23')+1`。二者目的不同，不能随意选择一种转换。还要把语法阶段和执行阶段分开：正常引号下的字符串加整数，能通过语法解析；弯引号 `“ ”` 不是 Python 字符串定界符，原样输入会先出现语法错误。

继续阅读：[第2章：字符串与类型转换](../topics/chapter-02.md)。

:::: question judgment-2 | Q02. 判断题

<div class="section-label">题干 <span>QUESTION</span></div>

 列表可以用 `find()` 函数来搜索数据是否在列表中。

::: answer

F（错误）。

:::

::: explanation

`find()` 是字符串方法，列表没有这个方法。例如 `'abc'.find('b')` 返回下标 `1`，但 `[1,2,3].find(2)` 会引发 `AttributeError`。

这里考查**成员判断与查找方法**：`2 in [1,2,3]` 判断是否存在，返回布尔值；`[1,2,3].index(2)` 查找首次出现的位置，返回下标 `1`。`index()` 找不到时会报错，因此只判断有无时直接用 `in`。

<!-- teaching-notes:start -->

**从本题理解：查存在、查位置与查全部匹配**

只判断有无时使用 `x in seq`，结果为布尔值。字符串 `find()` 返回第一次匹配的起始下标，找不到返回 -1；字符串和列表的 `index()` 也查首次位置，但找不到会引发 `ValueError`。列表没有 `find()` 方法。

```python
s = 'programming'
print(s.find('r'))      # 1
print(s.find('r', 2))   # 4：从下标 2 开始找
print('x' in s)         # False
```

不能写 `if s.find(x)` 判断存在：找到在下标 0 时是假值，没找到的 -1 反而是真值。应写 `if x in s` 或 `if s.find(x) != -1`。题目要求输出所有匹配位置时，需要遍历下标或重复搜索，而不是只调用一次查找；要求倒序位置时还需改变遍历方向。

:::: question judgment-3 | Q03. 判断题

<div class="section-label">题干 <span>QUESTION</span></div>

 字符串对象和元组对象是不可变对象，列表对象为可变对象。

::: answer

T（正确）。

:::

::: explanation

“可变”指对象创建后，能否原地修改其内容。列表可以执行 `a[0]=新值`、`append()`、`pop()`；字符串和元组不能直接给某个位置重新赋值。

这里考查**对象可变性与变量绑定**：`s=s+'x'` 可以执行，但这是生成新字符串再让 `s` 指向它，不是修改原字符串。元组若包含列表，内部列表仍可修改；不可变的是元组自身各位置保存的引用。

<!-- teaching-notes:start -->

**从本题理解：原地修改与生成新对象**

列表是可变对象，能原地修改元素或增删；字符串、元组不能更改自身位置上的引用。`s=s+'x'` 虽然能执行，但它创建新字符串并让名字 `s` 重新绑定，不能证明字符串可变。元组里的列表仍可改变，如 `t=([1],)` 后执行 `t[0].append(2)` 合法。

另一个常考区别是返回值：`a.sort()`、`a.reverse()`、`a.append(x)` 修改列表并返回 `None`；`sorted(a)`、`a[::-1]` 返回新列表。因此 `b=a.sort()` 后 `b` 不是已排序列表，而是 `None`。阅读代码时分别记录“原对象现在是什么”和“表达式返回了什么”，就能避免把二者混为一谈。

继续阅读：[第3章：列表修改与返回值](../topics/chapter-03.md)。

<!-- teaching-notes:end -->

:::: question judgment-4 | Q04. 判断题

<div class="section-label">题干 <span>QUESTION</span></div>

 列表 `lst=[12, -5, -22, -10, -26, 35, 0, 49, 3, -21]`，`lst[1::2]` 的结果是 `[12, -22, -26, 0, 3]`。

::: answer

F（错误）。

:::

::: explanation

切片格式是 `序列[start:stop:step]`，下标从 `0` 开始。`lst[1::2]` 表示从下标 `1` 起，每次前进 `2` 个位置，取下标 `1、3、5、7、9` 的元素，结果为 `[-5,-10,35,49,-21]`。

这里考查**切片起点与步长**：正步长时省略终点表示一直取到末尾。题目给出的 `[12,-22,-26,0,3]` 实际对应 `lst[::2]`，即从下标 `0` 开始取。

<!-- teaching-notes:start -->

**从本题理解：索引、切片与负步长**

索引 `a[i]` 取得一个元素，下标从 0 开始，负下标从尾部计数，`-1` 是最后一个元素。切片 `a[start:stop:step]` 取得一个新序列：从起点开始，每次前进步长，只要还没到终点就继续，终点本身不取。正步长时可用 `range(start,stop,step)` 列出目标下标。

```python
a = [10, 20, 30, 40, 50]
print(a[1:5:2])  # [20, 40]：下标 1、3
print(a[:-1])    # [10, 20, 30, 40]
print(a[::-1])   # [50, 40, 30, 20, 10]
```

切片越界会裁剪到合法边界，而单个索引越界会报错。负步长时默认起点和终点随方向改变，`a[::-1]` 的省略终点不等于显式写 `a[-1:-1:-1]`；后者是空列表。步长不能为 0。列表切片是浅拷贝，外层新建，内部可变对象仍可能共享。

继续阅读：[第3章：序列的访问及运算符](../topics/chapter-03.md)。

<!-- teaching-notes:end -->

:::: question judgment-7 | Q07. 判断题

<div class="section-label">题干 <span>QUESTION</span></div>

 表达式 `"34" in "1234"==True` 返回值是 `True`。

::: answer

F（错误）。

:::

::: explanation

`in` 和 `==` 都属于比较运算符，这里会形成链式比较：`"34" in "1234" == True` 等价于 `("34" in "1234") and ("1234" == True)`。前半部分为 `True`，后半部分为 `False`，所以整体为 `False`。

这里考查**链式比较**：它和 `1<x<10` 使用相同规则，不会先算出成员判断结果再与 `True` 比较。若只想判断子串是否存在，直接写 `"34" in "1234"` 即可；加括号后 `("34" in "1234")==True` 也为真。

<!-- teaching-notes:start -->

**从本题理解：链式比较会复用中间操作数**

`a < b < c` 按逻辑可理解为 `a < b and b < c`，并不是先把 `a < b` 的布尔值拿去与 `c` 比较。成员运算 `in` 也属于比较运算，所以 `'34' in '1234' == True` 中，中间操作数是字符串 `'1234'`，后一项比较的是 `'1234' == True`，结果为假。

加括号会改变分组：`('34' in '1234') == True` 先得到成员判断结果，因此为真。实际编程中直接写 `'34' in '1234'` 更清楚。链式比较还具有短路特性，前一项为假时不再计算后项；遇到混合比较符号时，把它拆成相邻两项的比较，再逐项分析最可靠。

:::: question judgment-8 | Q08. 判断题

<div class="section-label">题干 <span>QUESTION</span></div>

 `"12 "*3==" ".join(["12","12","12"])` 的输出是 `True`。

::: answer

F（错误）。

:::

::: explanation

字符串乘以整数会完整重复原字符串，包括原有空格。因此 `"12 "*3` 得到 `'12 12 12 '`，末尾仍有空格；`" ".join(["12","12","12"])` 得到 `'12 12 12'`，两者不相等。

这里考查**字符串重复、连接与精确比较**：`join()` 只在相邻元素之间插入分隔符，不在开头和结尾额外添加。排查空格问题可用 `repr()` 显示字符串边界，或用 `len()` 比较长度。

<!-- teaching-notes:start -->

**从本题理解：连接字符串与空格精确比较**

`分隔符.join(各字符串)` 只在相邻项之间放分隔符，不会自动在首尾添加。例如 `' '.join(['12','12','12'])` 为 `'12 12 12'`，而 `'12 '*3` 为 `'12 12 12 '`，末尾多一个空格，比较结果为假。

```python
parts = ['12', '12', '12']
s = ' '.join(parts)
print(repr(s))         # '12 12 12'
print(len(s))          # 8
```

`join()` 的元素必须是字符串，数值列表先用 `map(str,values)` 转换。`strip()` 能改变两端空白，但不能为了解决输出问题随意使用：若空格属于题目要求，去掉它就是改变答案。比较字符串时，先写出每一段内容和长度，再叠加 `print()` 自带的 `sep`，能更准确地定位多余空格。

继续阅读：[第3章：字符串和列表的互转](../topics/chapter-03.md)。

:::: question judgment-9 | Q09. 判断题

<div class="section-label">题干 <span>QUESTION</span></div>

 语句 `print("输出结果是{:8s}".format("this"))` 的输出是 `输出结果是□□□□this`，`□` 表示空格。

::: answer

F（错误）。

:::

::: explanation

`{:8s}` 中，`s` 表示按字符串格式输出，`8` 表示最小字段宽度。`this` 长度为 `4`，字符串默认左对齐，所以在右边补 `4` 个空格，实际为 `输出结果是this□□□□`。

这里考查**格式化宽度与对齐**：`<` 左对齐、`>` 右对齐、`^` 居中。若想得到题目所示结果，应写 `{:>8s}`。宽度是最小值，字符串长度超过 `8` 时不会被截断。

<!-- teaching-notes:start -->

**从本题理解：格式规格由填充、对齐、宽度和类型组成**

常见结构为 `[[填充字符]对齐方式][宽度][.精度][类型]`。`<` 左对齐、`>` 右对齐、`^` 居中；字符串默认左对齐，数值默认右对齐。宽度是最小宽度，不会截断过长内容。`d` 用于十进制整数，`s` 用于字符串，`.2f` 表示小数点后保留两位。

```python
print(f'|{"this":8s}|') # |this    |
print(f'|{1234:8d}|')   # |    1234|
print(f'{31:08b}')      # 00011111
print(f'{"11":0>5s}')  # 00011
```

先算内容本身长度，再用字段宽度减去它，才知道补几个字符。动态宽度应显式写成 `f'{s:^{width}}'`，格式串里的普通字母不会自动读取同名变量。浮点格式化的宽度还包含符号和小数点，精度不等于总字符数。

:::: question judgment-11 | Q11. 判断题

<div class="section-label">题干 <span>QUESTION</span></div>

 `[4,5]*3` 的结果是 `[[4,5],[4,5],[4,5]]`。

::: answer

F（错误）。

:::

::: explanation

列表乘以整数会重复其中的元素，不会自动把原列表嵌套成一个元素。因此 `[4,5]*3` 得到 `[4,5,4,5,4,5]`；若要三个子列表，形式应为 `[[4,5]]*3`。

这里考查**序列重复与引用共享**：`[[4,5]]*3` 的三个位置指向同一个内部列表，修改其中一个会同时影响另外两个。需要相互独立的子列表时，可写 `[[4,5] for _ in range(3)]`。

<!-- teaching-notes:start -->

**从本题理解：序列重复与内部引用共享**

字符串或列表乘整数表示重复，不是把内容解释成数值。`'23'*3` 为 `'232323'`，`[4,5]*3` 为 `[4,5,4,5,4,5]`，不会自动生成三个子列表。字符串原有的空格也会一起重复，所以 `'12 '*3` 在最后仍有一个空格。

若元素本身是可变列表，重复操作复制的是引用：`rows=[[0]*2]*3` 中三行是同一个对象，执行 `rows[0][0]=1` 会让三行都改变。要创建独立的行，应写 `rows=[[0]*2 for _ in range(3)]`。同样，列表 `+` 只连接一层，`[1,2]+[[3]]` 得到 `[1,2,[3]]`，不会递归展开内部列表。

:::: question judgment-14 | Q14. 判断题

<div class="section-label">题干 <span>QUESTION</span></div>

 执行语句 `m,n=int(input().split(","))` 时，输入 `3,4` 可以得到 `m` 和 `n` 的值分别为 3 和 4。

::: answer

F（错误）。

:::

::: explanation

输入 `3,4` 后，`input()` 得到字符串 `'3,4'`，`split(',')` 得到列表 `['3','4']`。`int()` 不能把整个列表一次转换成整数，所以程序在拆包前就会引发 `TypeError`。

这里考查**输入、拆分、逐项转换与拆包**：应写 `m,n=map(int,input().split(','))`，先将每一项转成整数，再分别赋值。拆分出的项目数也必须与左侧变量数匹配；若输入用空格分隔，则可用不带参数的 `split()`。

<!-- teaching-notes:start -->

**从本题理解：输入处理的四个步骤**

```python
line = input()

m, n = map(int, parts)
```

`int(parts)` 不会逐项处理，而会因参数是列表而报错。输入 `3,5` 应使用 `split(',')`。拆出的项目数和变量数不匹配会产生 `ValueError`；数字格式非法也会在转换时产生 `ValueError`。处理整行字符串时不要随意 `split()`，否则原有空格结构会丢失。

<div class="section-label">题干 <span>QUESTION</span></div>

 以下哪句打印出 `smith\exam1\test.txt`？

```text
A. print("smith\exam1\test.txt")
B. print("smith\\exam1\\test.txt")
C. print("smith\"exam1\"test.txt")
D. print("smith"\exam1"\test.txt")
```

::: answer

:::

::: explanation

普通字符串中的反斜杠用于引出转义序列，例如 `\t` 表示制表符、`\n` 表示换行。要输出一个真实的反斜杠，应在字符串字面量中写 `\\`，所以 B 能输出所需路径。

```python
path = r'smith\exam1\test.txt'

```

`r` 前缀可以减少路径中的转义处理，但原始字符串也有语法限制，例如不能以奇数个反斜杠紧接结束引号。查看 `repr(path)` 会得到便于观察转义的表示，不能把其中为展示而写出的双反斜杠误认为实际内容里有两个反斜杠。

:::: question choice-2 | Q02. 单选题

<div class="section-label">题干 <span>QUESTION</span></div>

 如果 `list1 = [1, 2, 3, 4, 5, 4, 3, 2, 1]`，那么以下哪个是 `list1[:-1]`？

```text
A. 0
B. [1, 2, 3, 4, 5, 4, 3, 2, 1]
C. [1, 2, 3, 4, 5, 4, 3, 2]
D. [0, 1, 2, 3, 4, 3, 2, 1, 0]
```

::: answer

C。

:::

::: explanation

`list1[:-1]` 从列表开头取到下标 `-1` 之前，最后一个元素不包含在结果中，所以得到 `[1,2,3,4,5,4,3,2]`。

这里考查**负索引与切片**：`-1` 表示最后一个元素，`-2` 表示倒数第二个元素。`list1[-1]` 取得单个元素，而 `list1[:-1]` 取得列表；类似地，`list1[-2:]` 取得最后两个元素。

<!-- teaching-notes:start -->

**从本题理解：索引、切片与负步长**

索引 `a[i]` 取得一个元素，下标从 0 开始，负下标从尾部计数，`-1` 是最后一个元素。切片 `a[start:stop:step]` 取得一个新序列：从起点开始，每次前进步长，只要还没到终点就继续，终点本身不取。正步长时可用 `range(start,stop,step)` 列出目标下标。

```python
a = [10, 20, 30, 40, 50]
print(a[1:5:2])  # [20, 40]：下标 1、3
print(a[:-1])    # [10, 20, 30, 40]
print(a[::-1])   # [50, 40, 30, 20, 10]
```

切片越界会裁剪到合法边界，而单个索引越界会报错。负步长时默认起点和终点随方向改变，`a[::-1]` 的省略终点不等于显式写 `a[-1:-1:-1]`；后者是空列表。步长不能为 0。列表切片是浅拷贝，外层新建，内部可变对象仍可能共享。

:::: question choice-3 | Q03. 单选题

<div class="section-label">题干 <span>QUESTION</span></div>

 要把 5 加到列表 `lst` 的末尾，用的是哪一句？

```text
A. lst.add(5)
B. lst.append(5)
C. lst.addLast(5)
D. lst.addEnd(5)
```

::: answer

B。

:::

::: explanation

`lst.append(5)` 会把整数 `5` 作为一个元素追加到列表末尾，其他选项不是列表提供的方法。注意 `append()` 修改原列表，返回 `None`，不要写成 `lst=lst.append(5)`。

这里考查**列表添加元素的方法**：`append(x)` 添加一个整体；`extend(可迭代对象)` 逐项追加，例如 `[1].extend([2,3])` 后列表为 `[1,2,3]`；`insert(i,x)` 则在指定位置插入。`add()` 是集合常见的添加方法。

<!-- teaching-notes:start -->

**从本题理解：列表方法按“位置”还是“值”操作**

```python
a = [3, 4, 3]
a.remove(3)

print(a.pop()) # 3
print(a)       # [4]
```

元素删除后，右边元素的下标会前移；跟踪程序时每一步都应写出新的列表。`append()`、`remove()`、`sort()` 等修改列表后返回 `None`，不能把它们的返回值再赋给列表变量。`pop()` 则特意返回被删元素，是这一组题里很容易混淆的差别。

**从本题理解：遍历元素、遍历下标与拆包**

`for row in students` 每次拿到一整行，`row[0]` 再访问其中第一个字段；`for number,name in students` 则要求每行恰好有两个元素，并直接拆包。二维访问 `students[i][j]` 是先选第 i 行，再选该行第 j 项，不是同时对一个平面下标取值。

```python
students = [(1001, '张三'), (1002, '李四')]
for index, (number, name) in enumerate(students):
    print(index, number, name)
```

只需要内容时直接遍历元素；还需要下标时使用 `enumerate()`；需要特定方向或步长时再遍历 `range()`。拆包不会自动转换类型，字符串拆包得到的仍是字符。也尽量避免用 `id`、`list` 等内置名称命名变量，防止遮蔽其功能。

:::: question blank-10 | Q10. 填空题

<div class="section-label">题干 <span>QUESTION</span></div>

 `print(sum((1,3,5,7,9))/len((1,3,5,7,9)))` 的输出是 _____。

::: answer

`5.0`。

:::

::: explanation

元组共有 `5` 个元素，总和为 `1+3+5+7+9=25`，所以表达式计算 `25/5`。Python 3 中 `/` 对整数执行的也是普通除法，结果为浮点数 `5.0`，不能填成 `5`。

这里考查**聚合函数与除法类型**：`sum()` 求和，`len()` 统计元素个数，两者结合常用于求平均值。`//` 才是向下取整除法，例如 `25//5` 为 `5`、`-3//2` 为 `-2`；计算平均值前还要避免序列为空。

<!-- teaching-notes:start -->

**从本题理解：计数、求和、平均值与最值累积**

`len()` 数元素个数，`sum()` 累加数值，平均值是 `sum(values)/len(values)`。Python 3 的 `/` 返回普通除法结果，因此 25 除以 5 输出 `5.0`；换成 `//` 会改变含义，不能为了输出没有小数点就随意换运算符。空序列需要先处理，避免除以 0。

:::: question blank-11 | Q11. 填空题

<div class="section-label">题干 <span>QUESTION</span></div>

 下面程序的输出是 _____。

```python
t=1
t,a=2,t+1
print(a)
```

::: answer

`2`。

:::

::: explanation

执行 `t,a=2,t+1` 时，先计算整个右侧。此时旧的 `t` 为 `1`，右侧两个值是 `2` 和 `2`，随后再分别赋给左侧的 `t`、`a`，因此输出 `2`。

这里考查**多目标拆包赋值的求值顺序**：不是先让 `t=2` 再计算 `a=t+1`，所以 `a` 不会得到 `3`。常见的交换写法 `a,b=b,a` 也利用此规则，无需额外的临时变量。

<!-- teaching-notes:start -->

**从本题理解：赋值、表达式与拆包顺序**

普通 `=` 是赋值语句，不是比较运算 `==`，不能直接嵌入 `x=(y=z+1)+1` 这种表达式。若两个名字都要接收同一个结果，可写 `x=y=z+1`。`i*=3+5` 要先求出整个右侧，数值情形下相当于 `i=i*(3+5)`，不是 `i=i*3+5`。

拆包赋值先求整个右侧，再从左到右赋给各目标。若旧 `t=1`，`t,a=2,t+1` 先得到右侧 `(2,2)`，所以 `a=2`；交换 `a,b=b,a` 也利用此规则。右侧必须可迭代且元素数量匹配：整数 34 不能直接拆成 3 和 4，字符串 `'3 4'` 则有 3 个字符，而不是两个数。

```text
456
```

```python
s = str(int(input()))
```

:::

::: explanation

<!-- teaching-notes:start -->

**解题步骤与边界**

**从本题理解：文本形式与数值类型转换**

```python
print(int('11', 2))    # 3：以二进制解析
```

:::: question programming-2 | Q02. 计算有n个字符串中最长的字符串长度

<div class="section-label">题干 <span>QUESTION</span></div>

 编写程序，计算 n（1<n<10）个字符串中最长的字符串的长度。前导空格不要计算在内！

**输入格式：** 第一行输入 n，接下来的每行输入一个字符串。

**输出格式：** 在一行中输出最长的字符串的长度，按样例输出 `length=长度`。

**输入样例：**

```text
4
        blue
yellow
red
green
```

**输出样例：**

```text
length=6
```

::: answer

```python
n = int(input())
longest = 0
for _ in range(n):
    s = input().lstrip(' ')
    longest = max(longest, len(s))
print(f"length={longest}")
```

:::

::: explanation

先读入字符串个数，再逐行处理。`input()` 读取整行并去掉行尾换行符，但保留字符串中的空格；`lstrip(' ')` 只去掉左侧普通空格。每读一行，就用 `max(longest,len(s))` 更新当前最大长度。

这里考查**逐行输入、单侧清理与最值累积**：不能用 `strip()`，否则会连末尾空格一起删除；也不能直接按空格拆分整份输入，否则会破坏每行字符串。最后用 f-string 输出严格的 `length=数值`，等号两侧不加空格。

<!-- teaching-notes:start -->

**解题步骤与边界**

每轮读一整行，清理左侧普通空格后测长度，再与目前最长值比较。例如一行是三个前导空格、abc、两个尾随空格，处理后长度是 5 而不是 3。输入数量控制循环次数，不应把所有词拆开当成不同字符串。

**从本题理解：清理哪一端，保留哪些字符**

`strip()` 清理两端空白，`lstrip()` 仅清理左端，`rstrip()` 仅清理右端；它们都返回新字符串，保留中间空格。默认空白还包括制表符、换行符，而 `lstrip(' ')` 明确只清理普通空格。题目要求保留尾部空格时，不能用 `strip()` 替代单侧处理。

传入参数时，它表示“可被清理的字符集合”，不是一个固定前缀或后缀。例如 `'abbaXba'.strip('ab')` 得到 `'X'`，因为两端连续的 a、b 都被去掉。若只想删除一个完整前缀，可用 `removeprefix()`。输出多个清理结果时，别忘了 `print()` 默认还会在参数之间加一个空格，应把清理后的内容与输出分隔符分开计算。

<div class="section-label">题干 <span>QUESTION</span></div>

 回文就是字符串中心对称，从左向右读和从右向左读的内容一样。输入一个字符串，判断它是否为回文，只考虑数字和字母字符，字母大小写没有区别。

```text
A man,a plan; cnalPanama
```

```text
yes
```

```python
s = input()
```

:::

::: explanation

先用 `c.isalnum()` 筛出字母和数字，再用 `lower()` 统一字母大小写，最后通过 `''.join(...)` 拼成新字符串。样例处理后为 `'amanaplancnalpanama'`，与反转后的结果相同，因此输出 `yes`。

<!-- teaching-notes:start -->

**解题步骤与边界**

先标准化再比较，避免让标点或大小写影响回文定义。可用短例子 `A,b,a!` 推演：筛选并转小写后为 `aba`，左右对称。也可以用左右双指针逐项比较来理解切片比较的含义；不同写法必须保留相同的筛选规则。

```python
text = 'A1-b2!'
clean = ''.join(c.lower() for c in text if c.isalnum())

```

先确认题目允许哪些字符：`isalnum()` 包括 Unicode 字母数字，十六进制则只能从 `0123456789abcdefABCDEF` 选择。还要明确空结果如何处理、是否保留空格、比较是否区分大小写。不要为简化代码而擅自删除题目没有要求忽略的字符。

:::: question programming-5 | Q05. 统计满足特定条件的字符数

```python
a = input()
b = input()
count = 0
for c in a:
    if c in b:
        count += 1
print(count)
```

:::

::: explanation

遍历的是没有重复字符的 A，对每个字符只判断一次它是否存在于 B，不统计它在 B 中出现了几次。样例中 A 的 `E`、`O` 出现在 B 中，而小写 `o` 不等于大写 `O`，最终计数为 `2`。

这里考查**成员运算与计数对象的选择**：`c in b` 返回布尔值，存在就令计数器加一。不能反过来直接遍历 B 计数，否则 B 中重复字符可能被多算；若数据很大，可先做 `set(b)`，再对集合进行成员判断。

**解题步骤与边界**

去重又是另一种任务：集合可以快速记录见过的字符，但直接转集合不能保留原输入顺序。需要保序时，遍历原序列，用集合判断是否首次出现，再追加到结果。统计两个字符串共有多少字符前，也要看题目保证哪一边不重复；遍历重复的一边可能把同一个字符多算。大小写、空格、标点是否参与比较，都必须由题意决定。

:::: question programming-6 | Q06. 打印m到n的等腰图形

<div class="section-label">题干 <span>QUESTION</span></div>

 在同一行输入两个正整数 m 和 n，以一个空格分隔，满足 1≤m≤n≤9。输出从 m 开始到 n 的等腰图形，形状见样例。

**输入格式：** 在同一行输入 m 和 n，以一个空格分隔。

**输出格式：** 每行数字从 1 递增到当前行数值，再递减回 1；左侧补空格，使图形居中。

**输入样例 1：**

```text
2 4
```

**输出样例 1：**

```text
  121
 12321
1234321
```

**输入样例 2：**

```text
3 3
```

**输出样例 2：**

```text
12321
```

::: answer

```python
m, n = map(int, input().split())
for i in range(m, n + 1):
    left = ''.join(str(j) for j in range(1, i + 1))
    right = ''.join(str(j) for j in range(i - 1, 0, -1))

```

:::

::: explanation

外层循环依次取峰值 `i=m～n`，并不是每行从数字 m 开始。每行前半段为 `1～i`，后半段为 `i-1～1`，两段连接后共有 `2i-1` 个数字，峰值只出现一次。

这里考查**range 边界、字符串拼接与居中对齐**：最底行宽度为 `2n-1`，与当前行相差 `2(n-i)`，所以左侧补 `n-i` 个空格即可。反向部分使用 `range(i-1,0,-1)`；输出不额外补右侧空格，避免格式错误。

<!-- teaching-notes:start -->

**解题步骤与边界**

外层 i 从 m 到 n 表示每行的峰值；递增段为 1～i，递减段为 i-1～1，峰值不能重复。把两段各自用 `range()` 构造后连接，左侧补 n-i 个空格。对 m=n 的情况也只输出一行，而不是从第 1 行开始补出整座图形。

**从本题理解：把图形拆成行号和行内规律**

先确定第 i 行由哪几段组成，再决定循环。星号三角形常见规律是第 i 行有 i 个星号；等腰数字图形则可以拆成左侧空格、递增段和递减段。最高值只出现一次，所以递减段从 i-1 开始，而不是再次从 i 开始。

假设所有数字都占一个字符，峰值为 i 的回文数字行宽为 `2*i-1`，最终行峰值为 n，则左侧空格数是 n-i。若数字可能达到两位，必须重新核对题目限制和实际字符宽度，不能继续套单字符公式。输出前用小输入手算每行的前导空格、分隔符、行尾空格和换行；不要用网页里看起来相近的形状替代精确字符比较。

:::: question programming-7 | Q07. 十进制纯小数转成二进制小数

<div class="section-label">题干 <span>QUESTION</span></div>

 在一行输入一个正的纯小数，把它转换成二进制小数，在下一行输出。如果转换结果超过 10 位或者出现无穷，则保留二进制小数部分的前 10 位。保证输入值转成二进制后不小于 `0.0000000001`。

**输入格式：** 输入一个正的纯小数 n。

**输出格式：** 输出 n 的二进制小数；提前转换完毕时无需补零。

**输入样例 1：**

```text
0.75
```

**输出样例 1：**

```text
0.11
```

**输入样例 2：**

```text
0.1324
```

**输出样例 2：**

```text
0.0010000111
```

::: answer

```python
from fractions import Fraction

x = Fraction(input().strip())
bits = ''
for _ in range(10):
    x *= 2
    bit = int(x)
    bits += str(bit)
    x -= bit
    if x == 0:
        break
print('0.' + bits)
```

:::

::: explanation

十进制纯小数转二进制采用“乘 2 取整”：将余数乘 `2`，整数部分就是下一位二进制数，再留下小数部分继续。例如 `0.75×2=1.5` 取 `1`，`0.5×2=1` 再取 `1`，余数归零，得到 `0.11`。

这里考查**小数进制转换、循环终止与精度**：余数为零就提前结束，否则最多取 `10` 位，直接截断而不四舍五入。`Fraction` 从输入字符串构造精确分数，避免先转换成 `float` 引入误差；例如十进制 `0.1` 的二进制是无限循环小数，不能总等余数归零才停止。

<!-- teaching-notes:start -->

**解题步骤与边界**

维护剩余小数，每次乘 2 后提取整数位，再把剩余小数留给下一轮。例如 0.625 依次得到位 1、0、1。精确分数能可靠判断余数是否为零；仍需最多 10 轮的上限处理无限循环表示。输出按题意截断，不对第 11 位做四舍五入。

**从本题理解：整数和小数的进制转换方向不同**

整数部分用“除基取余、逆序排列”；纯小数部分用“乘基取整、顺序排列”。例如 $0.625\times2=1.25$ 取 1，$0.25\times2=0.5$ 取 0，$0.5\times2=1$ 取 1，于是 $0.625=(0.101)_2$。整数 19 是 `10011`，若题目要求整数部分占 8 位，再在左侧补零。

为什么有些小数算不完？一个最简分数能用有限二进制小数表示，当且仅当分母只含质因子 2，例如 $5/8$ 可以，$1/10$ 不可以。因此循环既要判断余数是否归零，也要遵守题目给定位数上限；截断和四舍五入是两种不同要求。精确转换十进制输入时，可用 `Fraction(输入字符串)`，避免先转 `float` 造成近似。
